# 同类跨用户对比约束

[English](README.md) | [简体中文](README.zh-CN.md) | [实验索引](../README.zh-CN.md)

在分类器实际使用的 40 维 TCN 表示上直接加入权重 0.05、温度 0.1 的监督对比损失。
正样本为 outer-train 内同类不同用户，负样本为不同类别；同类同用户样本被忽略，不会
被误当成负样本。

训练信号确实生效：每折每个 epoch 至少有 2,118 个有效 anchor，且五折对比损失都持续
下降。但 Temporal 从 2,847 降至 2,843，T+V 从 2,889 降至 2,888：纠正 5、破坏 6、
净 -1，A–E 为 `-1/-1/+1/0/0`；subject-macro 和有效输入子集也下降。预注册方案失败，
未扫描权重或温度。
