# 温和骨长重定向

[English](README.md) | [简体中文](README.zh-CN.md) | [实验索引](../README.zh-CN.md)

第一版绝对骨长重建在训练前的几何质检中失败：最大归一化位移达到 2.474。通过质检的
v2 对左右对应骨组使用整段固定的 ±5% 比例，同时保留每帧投影长度变化、方向、root
轨迹、置信度和缺失帧；平均/最大位移为 0.0153/0.1460。

训练样本确定性地按 50/50 使用原始或重定向输入，held-user 验证只用原始输入。
Temporal 从 2,847 降至 2,846，T+V 从 2,889 降至 2,888；没有纠正样本、破坏 1 条，
A–E 为 `0/-1/0/0/0`。增强足够稳定但没有正向泛化证据，因此未继续扫描扰动幅度。
