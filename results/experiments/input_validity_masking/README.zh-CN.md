# 分支有效性损失屏蔽

[English](README.md) | [简体中文](README.zh-CN.md) | [实验索引](../README.zh-CN.md)

有效性来自源文件实际解码，而非黑像素启发式：Depth 或 IR 至少有一张图片通过 PIL
校验时 Visual 有效；至少一帧通过现有骨架解析器时 Skeleton 有效。审计发现 3,036 条中
有 103 条两个主输入都无效，它们贡献了冻结发布模型 133 个 OOF 错误中的 73 个；其中
用户 5 占 60 条、类别 36 占 30 条。

配对实验保留全部样本前向，只改变 CE mask；验证仍包含所有 held-user 样本。冻结门控
T+V control 为 2,889 条正确；仅屏蔽 Visual 为 2,888，仅屏蔽 Temporal 为 2,885，
两者同时屏蔽仍为 2,885：纠正 8、破坏 12、净 -4，A–E 为 `-1/-5/+2/0/0`。
有效输入子集和 subject-macro 同样下降。缺失输入解释了大量不可约错误，但仅做损失
屏蔽不能改善泛化，因此拒绝晋级。
