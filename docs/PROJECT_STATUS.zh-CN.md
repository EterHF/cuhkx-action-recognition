## 剩余研究机会

1. **先改善验证可信度。** 在目标域适配前固定上游权重与配方，并从一开始排除 outer-held
   用户。内层选择需要真正嵌套的训练输入。不能事后把已反复查看过的用户分组称为新的
   确认性集合；有新的独立用户数据时优先使用它。
2. **改进表示或验证教师蒸馏。** 用训练时更强的公开预训练视频／骨架教师改进小模型表示，
   再检查量化后的实际部署精度，可能比继续修正几个 logits 更有价值。这只是后续假设，
   尚未在本仓库证明有效，不能预报涨分。
3. **补足缺失主输入的时序证据。** 103 条训练样本缺少两个主输入，当前 thermal 接管仍不稳。
   若继续，需要新的时序表示或预训练依据，并检查收益是否覆盖多个用户；不继续扫描旧
   TSN／TSM 的随机种子、裁剪参数或融合比例。

上述是后续研究优先级。本次整理与推送没有再开启新训练或追加榜单提交。

## 发布与最终候选

原 strictV3 保持不变。推荐 `55712568` 与 `56036959`：前者是完整发布基线，后者删除
弱 Fusion 分支且无需拟合新参数。两者公开分数均为 0.97512，预测并不完全重复。
T+V 早期 2,909 OOF 的 Visual scale 与部署不一致，**不以该增益作为最终选择依据**。
选择理由是可复现、同等已知公开表现、结构简化和有限的预测差异，不能保证 private 优势。
